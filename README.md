# Psicología Clínica II — Resúmenes Finales (UCASAL 2026)

## Convención Tipográfica de Estudio

Los 18 módulos utilizan una **doble tipografía** para agilizar tanto el estudio profundo como el repaso previo al examen:

1. **Tipografía principal (Sans-Serif — Segoe UI / Arial):** Contenido nuclear indispensable para el examen final (definiciones centrales, axiomas, criterios diagnósticos, clasificaciones, bloques verdes de diferenciación conceptual, objetivos, proceso y técnicas con su autor).
2. **Tipografía secundaria (Serif — Georgia, recuadros grises indentados):** Contexto histórico o biográfico, aclaraciones de enlace, notas de clase y ejemplos clínicos ilustrativos.
